# Mercury — Data Directory

This folder contains all data used by the Mercury STI/STD AI chatbot.
Some files are committed to the repo; others are too large and must be generated locally.

## What each file contains

### `patient_records.json` ✅ committed
Six synthetic STD patient profiles generated by [Synthea](https://github.com/synthetichealth/synthea).
Contains: hashed patient ID, SHA-256 hashed name, date of birth, diagnoses, medications, HIV status.
Address and city fields have been removed. Full names are SHA-256 hashed.
**No real patients — all data is synthetic.**

### `rag_chunks.json` — generated
The RAG knowledge corpus used by the chatbot. Built from two sources:
- **CDC STI Treatment Guidelines 2021** (PDF → 500-char chunks)
- **WHO STI Guidelines** (PDF → 500-char chunks)
- **15,503 curated STD Q&A conversations** from `ruslanmv/ai-medical-chatbot`

### `std_conversations.csv` — generated
15,809 STD-relevant doctor–patient Q&A pairs filtered from the
[ruslanmv/ai-medical-chatbot](https://huggingface.co/datasets/ruslanmv/ai-medical-chatbot) HuggingFace dataset.

**Privacy note:** This dataset originates from HealthCareMagic, a real online medical
consultation platform. The patient questions are written by real people describing
their own symptoms and personal medical situations. They were not generated or
synthetic. These individuals did not consent to their questions being included in
an AI training corpus or RAG retrieval system.

### `rag_docs/` — downloaded manually
Source PDF files for the clinical guidelines:
- `cdc_sti_guidelines_2021.pdf` — [CDC STI Treatment Guidelines 2021](https://www.cdc.gov/std/treatment-guidelines/default.htm)
- `who_sti_guidelines.pdf` — [WHO STI Guidelines](https://www.who.int/reproductivehealth/publications/rtis/9789241549684/en/)

### `faiss_index.bin` + `faiss_metadata.pkl` — generated
Vector similarity index built from `rag_chunks.json` using `all-MiniLM-L6-v2` embeddings.
Not currently used by the app (app uses keyword search); built for future semantic search upgrade.

## Setup for a new user

Run these steps in order from the `data_processing/` directory:

```bash
cd data_processing/
pip install -r requirements.txt
```

### Step 1 — Get the PDFs
Download the two PDF files and place them in `data/rag_docs/`:
- [CDC STI Guidelines 2021](https://www.cdc.gov/std/treatment-guidelines/default.htm)
- [WHO STI Guidelines](https://www.who.int/reproductivehealth/publications/rtis/9789241549684/en/)

### Step 2 — Get the conversation dataset
Downloads from HuggingFace and filters to STD-relevant rows (~15k conversations):
```bash
python filter_conversations.py
```

### Step 3 — Build the RAG corpus
Merges PDF chunks + filtered conversations into one file:
```bash
python build_rag.py
```
Output: `data/rag_chunks.json` (~34k chunks, ~23 MB)

### Step 4 — (Optional) Build the vector store
Only needed if switching to semantic search:
```bash
python build_vector_store.py
```
Output: `data/faiss_index.bin` + `data/faiss_metadata.pkl`

### Step 5 — (Optional) Rebuild patient records
Requires running Synthea locally first. See the main `mercury_setup_guide.md`:
```bash
python build_patient_records.py
```

## Notes on privacy

- `patient_records.json` contains **synthetic data only** (generated by Synthea, not real patients)
- Full names are SHA-256 hashed; addresses have been removed
- The `std_conversations.csv` dataset is publicly available on HuggingFace
- No real patient data is stored anywhere in this repository
