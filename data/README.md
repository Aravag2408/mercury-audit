# data/

RAG corpus and patient data for Mercury. Heavy files are gitignored and shared separately.

| File | In git | Generated by | Contents |
|---|---|---|---|
| `rag_chunks.json` | No (~23MB) | `data_processing/build_rag.py` | ~34k text chunks: CDC/WHO guidelines + 15,503 STD Q&A pairs |
| `patient_records.json` | Yes | `data_processing/build_patient_records.py` | 6 synthetic patient profiles (anonymised, no real patients) |
| `std_conversations.csv` | No (~15MB) | `data_processing/filter_conversations.py` | 15,503 STD-relevant Q&A rows from HuggingFace |
| `rag_docs/` | No | Downloaded manually | Source PDFs: CDC STI Guidelines 2021, WHO STI Guidelines |

## Rebuilding rag_chunks.json from scratch

If you don't have the pre-built corpus, build it:

```bash
cd data_processing
pip install -r requirements.txt

# Download source PDFs into data/rag_docs/ first (see data_sources.md for URLs)

python build_rag.py
# outputs: data/rag_chunks.json (~34k chunks)
```

## Privacy note

`std_conversations.csv` originates from the `ruslanmv/ai-medical-chatbot` HuggingFace dataset, which was scraped from HealthCareMagic — a real online medical consultation platform. The patient questions are real people describing their own symptoms. They did not consent to being included in this system. This is part of the audit's static corpus finding.

`patient_records.json` contains **synthetic data only** — generated programmatically, not real patients.
